# 🌤️ SkyMood — Pop Weather & Vibe Check

SkyMood is a vibrant, neo-brutalist real-time weather application built with HTML, CSS, and Vanilla JavaScript. It fetches live meteorological data and offers dynamic lifestyle recommendations—all without requiring any API keys or configuration.

![SkyMood Preview](https://img.shields.io/badge/Style-Neo--Brutalist-FF6B6B?style=for-the-badge)
![API](https://img.shields.io/badge/API-Open--Meteo-4ECDC4?style=for-the-badge)

---

## ✨ Features

- 🔍 **Real-Time Autocomplete Search:** Instant city search with debounced API requests (powered by Open-Meteo Geocoding).
- 📊 **Detailed Weather Metrics:** Displays temperature, "feels like", humidity, wind speed, UV index, precipitation, and air pressure.
- 💡 **Contextual Weather Tips:** Dynamically generates clothing advice, activity suggestions, and safety tips based on current weather conditions.
- 🎨 **Anti-Corporate / Neo-Brutalist Aesthetic:** High contrast design with bold typography (`Fredoka` & `Plus Jakarta Sans`), hard shadows, and vibrant pop colors.
- 🔑 **Zero Configuration Needed:** Powered entirely by free, public REST APIs with no authentication tokens or API keys needed.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Typography:** Google Fonts (`Fredoka`, `Plus Jakarta Sans`)
- **API Engine:** [Open-Meteo Free Weather API](https://open-meteo.com/)
